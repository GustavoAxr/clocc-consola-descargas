# CLOCC Consola · descargas

La consola de escritorio de CLOCC para las computadoras de cada sitio: da de alta
los relojes checadores y deja corriendo el agente que sube sus registros.

Descarga la última versión desde **[Releases](../../releases/latest)**:

| Sistema | Archivo |
|---|---|
| Windows 10, 11 y Server | `clocc-consola-windows-instalador.exe` |
| Ubuntu 24.04 con escritorio | `clocc-consola-ubuntu-amd64.deb` · `sudo apt install ./clocc-consola-ubuntu-amd64.deb` |
| macOS (para pruebas) | `clocc-consola-macos.zip` · sin firma de Apple: la primera vez, clic derecho › Abrir |
| Ubuntu sin escritorio | `clocc-agente-ubuntu-sin-escritorio.pdf` · la guía con los comandos del agente |

Las huellas SHA-256 de cada archivo están en `SHA256SUMS.txt` del mismo release.

Este repositorio solo publica los ejecutables; se actualiza solo con cada versión.
